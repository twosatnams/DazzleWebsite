Dazzle

Built from a love of ballroom.

Dazzle was a software project created to modernize ballroom competition management. Drawing on my experience as a competitive dancer and software engineer, I set out to improve the experience for organizers and dancers.

The project is no longer in active development and is not currently available as a hosted service. This page preserves its story.
